# Lighting Classification

Исследовательский проект по классификации изображений по уровням освещённости с использованием методов Computer Vision для курса по нейронным сетям для анализа изображений.

## Обзор

Цель проекта — исследовать и реализовать подходы к классификации изображений по трём упорядоченным категориям освещённости:

- `dark`
- `normal`
- `bright`

Особое внимание уделяется исследованию исходного датасета, анализу визуальных характеристик изображений, экспериментам с представлениями данных и оценке применимости различных методов классификации.

## Dataset

Исходный датасет содержит 1500 изображений, распределённых между тремя классами:

| Class | Number of images |
|---|---:|
| dark | 500 |
| normal | 500 |
| bright | 500 |
| **Total** | **1500** |

Изображения представлены в формате PNG и имеют RGB-цветовое представление.

Исходные данные отслеживаются с использованием [DVC](https://dvc.org/). Сами файлы датасета не хранятся непосредственно в Git.

## Research

Исследование включает следующие направления:

- Exploratory Data Analysis (EDA).
- Анализ распределений и статистических характеристик изображений.
- Исследование цветовых каналов RGB и относительной яркости (luminance).
- Извлечение и анализ визуальных эмбеддингов.
- Эксперименты с методами кластеризации.
- Разработка и оценка моделей классификации.

Дополнительные исследовательские направления и запланированные эксперименты фиксируются в [BACKLOG.md](BACKLOG.md).

## Environment Setup

Для управления Python-окружением и зависимостями используется [uv](https://docs.astral.sh/uv/).

Установка зависимостей:

```bash
uv sync
```

## Data Management

Для версионирования данных используется DVC.

Получение данных из настроенного DVC remote:

```bash
uv run dvc pull
```
